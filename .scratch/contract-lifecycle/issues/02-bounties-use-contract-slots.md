# Should open Bounties use Contract slots?

Status: needs-triage

Open Bounties count against the board’s Contract cap and never expire. Each
standing unanswered Bounty on an active Lair can occupy a slot indefinitely;
enough Bounties prevent new Contracts and raids from reaching the board.

This is questionable because work to recover Holdings competes with standing
Lair work, so companies can lose access to Contracts until a Bounty is taken.

Possible rules:

- Keep one shared cap for all open work and describe it as the board’s work cap.
- Count only Contracts against the existing cap; allow uncapped Bounties.
- Give Contracts and Bounties separate caps or reserved board slots.

Leave the current behaviour unchanged until the rule is decided.
