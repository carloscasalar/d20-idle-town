Being contract — prototype

Throwaway prototype for the wayfinder ticket "Being contract". Not part of src/.

The question. What does a Being implement, as code? A Nature is a list of need rules that read only the Being's state and Knowledge and give Needs, each with an Urgency from 0 to 100. A Mind is consulted only when the Being has no Plan, a step failed, requests reached it as an Owner, or a Need passed its Resolve. It returns a Decision with a Reason. The Being then takes its Plan's next Action, one per Tick, without asking the Mind again.

Here Brom and Ilsa share the same fighter Nature but have different Minds: Brom is bold, Ilsa is cautious. Mara keeps the potion shop and is the Owner of its potions. Press Next Tick and watch who gets consulted, and why.

The world here is a stub, not the Tick settlement design. It only applies Actions and hands back outcomes. The ticket "Tick settlement" will decide how Actions are gathered, ordered and settled, how Claims and Contests work, and how Actions that last several Ticks work. The stub also leaves out Groups, how Knowledge is learned, and the Journal format and configuration.

type Urgency = number                     // integer 0–100, comparable across one Being's Needs
type Need = { kind: string; urgency: Urgency; note: string }
type NeedRule<S, K> = (state: S, knowledge: K) => Need | null   // no world in the signature
type Nature<S, K> = { name: string; rules: NeedRule<S, K>[] }

type Action = { kind: string; [arg: string]: unknown }
type Plan = { forNeed: string | null; steps: Action[]; next: number; resolve: Urgency; waiting?: true }

type Trigger = 'no-plan' | 'plan-ended' | 'need-gone' | 'step-failed' | 'resolve-passed'
type Failure = { action: Action; how: 'refused' | 'contest-lost' | 'impossible'; why: string }
type Reason = string

type Decision =
  | { kind: 'commit';   forNeed: string; steps: Action[]; resolve: Urgency; reason: Reason }
  | { kind: 'carry-on'; resolve: Urgency; reason: Reason }   // keep the Plan, set a new Resolve
  | { kind: 'wait';     resolve: Urgency; reason: Reason }   // nothing to do until a Need passes Resolve

type Request = { id: string; from: BeingId; fromName: string; action: Action }
type Answer = { request: string; accept: boolean; reason: Reason }

interface Mind<S, K> {
  decide(c: { trigger: Trigger; brokenBy?: Need; failure?: Failure; plan?: Plan;
              needs: Need[]; state: S; knowledge: K; rng: Rng }): Decision
  answer(c: { requests: Request[]; needs: Need[]; state: S; knowledge: K; rng: Rng }): Answer[]
}

// The Being's side of a Tick, all without the world:
takeTurn(being, nature, mind, rng)  => { being, needs, consulted, decision, action }
afterOutcome(being, outcome)        => being   // success moves to the next step; failure is kept for the Mind
type Outcome = { ok: true; note?: string } | { ok: false; how: Failure['how']; why: string }
