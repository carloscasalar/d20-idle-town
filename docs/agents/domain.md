# Domain docs

This is a single-context repo. Engineering skills should use the project's domain language and respect recorded decisions.

## Before exploring

- Read root `CONTEXT.md` when it exists. Use its terms in issue titles, proposals, hypotheses, and tests.
- Read relevant ADRs in `docs/adr/` when they exist. Flag a proposal that contradicts one.
- Read `README.md` and `docs/ARCHITECTURE.md` for the current simulation concepts and documented architecture.

`CONTEXT.md` and ADRs are created when terms or decisions are resolved. Their absence does not block exploration.
